# 📊 Sales Insights Dashboard
A dynamic **Sales Insights Dashboard** built using **Power BI** and **SQL**, analyzing a relational database to uncover revenue trends, regional market performance, and customer buying patterns.

---

## 🖼️ Dashboard Preview
![Sales Insights Dashboard](Sales%20Db.png)

---

## 🛠️ Tech Stack
- **Power BI** – Interactive visualizations & dashboard
- **SQL** – Data extraction & transformation queries
- **Relational Database** – Customers, Products, Markets, Dates, Transactions

---

## 📌 Key Features
- 📈 Revenue trend analysis over time
- 🌍 Regional & market-wise performance breakdown
- 👥 Customer buying pattern insights
- 🔄 Interactive filters and drill-through reports
- 📦 Product-level sales analysis
